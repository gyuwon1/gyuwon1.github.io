2부는 스위칭이다. 스위치와 라우터는 Cisco IOS의 명령줄(CLI)로 설정하므로, 먼저 모드 구조와 기본 명령부터 익힌다.

## 명령 모드

IOS는 모드마다 쓸 수 있는 명령이 다르다. 현재 모드는 프롬프트 끝의 기호로 구분한다.

![IOS 명령 모드와 모드 이동 명령]({{ '/assets/img/ccna/day11-modes.svg' | relative_url }})

| 모드 | 프롬프트 | 할 수 있는 일 |
|------|----------|---------------|
| 사용자 EXEC | `Switch>` | 제한된 확인 명령 (ping, 일부 show) |
| 특권 EXEC | `Switch#` | 모든 show 명령, 설정 저장, 재부팅 |
| 글로벌 설정 | `Switch(config)#` | 장비 전체에 적용되는 설정 |
| 인터페이스 설정 | `Switch(config-if)#` | 특정 포트의 설정 |
| 라인 설정 | `Switch(config-line)#` | 콘솔, VTY(원격 접속) 설정 |

접속하면 사용자 EXEC에서 시작한다. `enable`로 특권 EXEC에 들어가고, `configure terminal`(약어 `conf t`)로 설정 모드에 들어간다. 설정 모드에서 `exit`은 한 단계 위로, `end`나 Ctrl+Z는 특권 EXEC로 바로 나간다.

## 기본 설정 예

```
Switch> enable
Switch# configure terminal
Switch(config)# hostname SW1
SW1(config)# enable secret MyPass123
SW1(config)# interface gigabitethernet 0/1
SW1(config-if)# description to-Router1
SW1(config-if)# exit
SW1(config)# line console 0
SW1(config-line)# password ConPass1
SW1(config-line)# login
SW1(config-line)# end
SW1# show running-config
```

- `hostname`은 장비 이름을 바꾼다. 프롬프트가 곧바로 바뀐다.
- `enable secret`은 특권 EXEC에 들어갈 때 묻는 암호를 해시로 저장한다. `enable password`는 평문으로 저장되므로 쓰지 않는다.
- `description`은 인터페이스에 메모를 남긴다. 어느 장비에 연결되는지 적어 두면 장애 때 도움이 된다.
- 콘솔 암호는 `password`로 정하고 `login`을 넣어야 접속 때 실제로 묻는다.

## 설정을 저장하는 방법

IOS에는 설정이 두 종류 있다. `running-config`는 RAM에 있는 현재 설정이고, `startup-config`는 NVRAM에 저장된 부팅용 설정이다.

![부팅 때 IOS와 startup-config가 RAM으로 올라가고 copy 명령으로 저장되는 흐름]({{ '/assets/img/ccna/day11-configs.svg' | relative_url }})

명령을 입력하면 running-config에 바로 반영된다. 하지만 RAM의 내용은 전원이 꺼지면 사라지므로, 저장하지 않고 재부팅하면 변경분이 없어진다.

```
SW1# copy running-config startup-config
SW1# write memory
```

두 명령은 같은 동작이다. 설정을 지우고 초기 상태로 돌리려면 다음과 같이 한다.

```
SW1# erase startup-config
SW1# reload
```

## 도움말과 편의 기능

- `?`를 입력하면 현재 모드에서 쓸 수 있는 명령을 보여 준다. `show ?`처럼 명령 뒤에 쓰면 다음에 올 수 있는 인자를 보여 준다.
- 명령은 겹치지 않는 선까지만 써도 된다. `conf t`, `int g0/1`, `sh run`이 그 예다.
- Tab 키로 명령을 자동 완성한다.
- 위쪽 화살표나 Ctrl+P로 이전 명령을 불러온다. `show history`는 입력한 명령 목록을 보여 준다.
- 잘못 입력하면 `% Invalid input detected`, `% Incomplete command`, `% Ambiguous command` 같은 메시지가 나온다. 각각 틀린 명령, 인자가 부족한 명령, 약어가 여러 명령에 걸리는 경우다.
- 설정 한 줄을 지우려면 같은 명령 앞에 `no`를 붙인다. `no shutdown`은 포트를 켜고 `shutdown`은 끈다.

## 자주 쓰는 확인 명령

```
SW1# show version
SW1# show running-config
SW1# show interfaces status
SW1# show ip interface brief
```

`show version`은 IOS 버전과 가동 시간, 메모리를 보여 준다. `show interfaces status`는 스위치 포트의 연결 상태, VLAN, 속도를 한 줄씩 보여 준다. `show ip interface brief`는 IP가 설정된 인터페이스의 주소와 상태를 요약한다.

## 일본어 IT 용어

명령은 「コマンド」, 설정은 「<ruby>設定<rt>せってい</rt></ruby>」, 권한은 「<ruby>権限<rt>けんげん</rt></ruby>」, 재시작은 「<ruby>再起動<rt>さいきどう</rt></ruby>」라고 한다. 이 중 <ruby>権限<rt>けんげん</rt></ruby>과 <ruby>再起動<rt>さいきどう</rt></ruby>은 오늘 일본어 단어 글에 나온다.

## 확인 문제

1. 프롬프트가 `Router#`일 때 현재 모드는? 이 모드에서 설정 모드로 들어가는 명령은?
2. 설정 모드 어디에서든 특권 EXEC로 한 번에 나가는 방법은 두 가지다. 무엇인가?
3. 인터페이스를 설정한 뒤 저장하지 않고 스위치를 재부팅하면 그 설정은 어떻게 되는가?
4. `enable secret`과 `enable password`를 둘 다 설정하면 어느 것이 쓰이는가?
5. `sh ip int br`처럼 줄여 쓴 명령이 동작하는 이유는?

1. 특권 EXEC 모드다. `configure terminal`로 글로벌 설정 모드에 들어간다.
